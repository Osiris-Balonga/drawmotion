# DrawMotion distribution notices

DrawMotion's original source is MIT licensed (see `drawmotion-MIT.txt`, emitted
from the root LICENSE during the build). Third-party works retain their licences.

- `bundled.md`: generated by Vite for JavaScript dependencies in the application
  bundle, including their copyright and licence text. Generated files are not
  committed; run `pnpm build` to reproduce them.
- `service-worker.md`: full MIT notices for the bundled Workbox 7.4.1 core,
  precaching, routing and strategies modules, generated from installed packages.
- `mediapipe-Apache-2.0.txt`: MediaPipe Tasks Vision 1.0.1, its Worker runtime
  and the unchanged Hand Landmarker full/float16/version 1 model. Copyright
  The MediaPipe Authors. The [official guide](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker)
  links the [model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20%28Lite_Full%29%20with%20Fairness%20Oct%202021.pdf),
  whose page 2 specifies Apache License, Version 2.0. Asset checksums and download
  provenance are in `public/vision/README.md` in the source repository.
- `geist-OFL.txt`: Geist variable font 5.3.0, from Fontsource; SIL OFL 1.1.
- `shadcn-MIT.txt`: shadcn/ui components adapted by DrawMotion and shadcn 4.19.0 CSS.
- `tailwindcss-MIT.txt`: Tailwind CSS 4.3.3.
- `tw-animate-css-MIT.txt`: tw-animate-css 1.4.0.

MediaPipe's SDK is built separately in a Worker; it is covered by the explicit
Apache notice, not assumed to appear in Vite's application-module report.
Lucide's mixed icon notices are preserved in full in `bundled.md`.

The DrawMotion symbol and onboarding PNG illustrations were generated with
OpenAI's image-generation tool for this project and selected/adapted by its
maintainer. They are not MediaPipe or Lucide artwork. The MIT grant applies to
the maintainer's rights in these project assets; it makes no claim of exclusive
rights in AI-generated material or of trademark clearance.
Installation icons are resized, padded copies of the same approved symbol;
`scripts/generate-pwa-icons.mjs` reproduces them without redrawing the artwork.

Build dependencies are not all shipped in this static site. Their own licences
remain available in the packages installed from the lockfile.
