## Offline release checks

These physical-device checks remain **pending**, independently of automated
Chromium results. Record browser/OS, date and exact build SHA for each session.

- Visit online without activating the camera or clicking any preparation control.
  Wait for automatic offline readiness, then close every app window, disable
  the connection, then reopen the installed app. Verify readiness and start the
  physical webcam for the first time while offline.
- Draw, erase, change color/style, regularize a shape, zoom/pan and export PNG.
  Reload offline and confirm the drawing is restored. Clear and reload again.
- Toggle connectivity while drawing. Expect discreet feedback, no disabled tools,
  no reload and automatic recovery of an interrupted initial download.
- Deny camera permission and recover via browser settings. Background and
  resume the installed app; the camera must pause safely.
- Open two old-version windows, deploy an approved update, and keep drawing.
  Neither window should reload. Close both, reopen, and verify the new build
  and preserved drawing. An interrupted download must preserve the old app.
- Check install/uninstall/reinstall and storage-denial behavior on actual
  Chrome/Edge. On a physical tablet, check landscape/portrait, touch and install
  instructions. Do not infer iPad/Safari support from Chromium emulation.
- Exercise the PWA rollback procedure before claiming rollback validation.
